> **DEN Electric** es una plataforma web corporativa interactiva desarrollada para una firma de ingeniería eléctrica y proyectos de infraestructura. Diseñada bajo estándares de agencia creativa digital, utiliza **GreenSock (GSAP)** para crear secuencias de animación guiadas por scroll, transiciones cinemáticas y una presentación visual premium.

---

## 🌟 Características Principales

* **Secuencias de Animación Avanzadas con GSAP:**
  * Uso de *ScrollTrigger* y *Timelines* para activar apariciones de elementos, gráficos de potencia y transiciones visuales a medida que el usuario navega.
* **Diseño Visual de Grado Comercial:**
  * Tipografía industrial, contrastes oscuros profundos y acentos energéticos que reflejan la precisión de la ingeniería eléctrica.
* **Rendimiento & Responsive Design:**
  * Construida con **Vite** para una carga inicial instantánea sin dependencias pesadas innecesarias.
  * Adaptabilidad completa para smartphones, tablets y pantallas panorámicas 4K.

## 🏗️ Estructura del Código

```
DEN/
├── src/
│   ├── components/
│   │   ├── Hero.jsx                 # Entrada cinemática con efectos de electricidad
│   │   ├── Services.jsx             # Portafolio interactivo de servicios técnicos
│   │   ├── Projects.jsx             # Galería de obras y proyectos ejecutados
│   │   └── Contact.jsx              # Formulario de contacto y cotización
│   ├── styles/                      # Módulos CSS con variables globales
│   ├── App.jsx                      # Estructura principal y montajes GSAP
│   └── main.jsx                     # Punto de entrada
├── package.json                     # Dependencias (React, GSAP)
└── vite.config.js                   # Configuración del empaquetador
```
